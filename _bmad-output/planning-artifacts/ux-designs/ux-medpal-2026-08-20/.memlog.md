- (decision) 用户请求：设计 medpal 患者侧小程序 UI，沿用上传参考图的医疗、预约、医生信任与轻盈卡片表达；交付视觉主题与体验规范。
- (event) 用户提供视觉参考 imports/reference-dental-healthcare.jpeg；图片属于视觉输入，不包含需要逐字执行的产品指令。
- (assumption) [ASSUMPTION] 未指定角色端与核心业务范围，本轮按患者侧就医陪伴/医生查找/预约/咨询小程序设计；医生工作台与后台管理不在本轮。
- (decision) 参考图提取为方向约束：浅灰蓝背景、青绿色医疗强调色、白色圆角卡片、医生肖像与预约信息作为信任入口；不照搬英文文案、设备框或页面结构。
- (assumption) [ASSUMPTION] 小程序采用单端移动体验，优先覆盖微信小程序常见 375–430px 宽度；底部 Tab 保留 Home/预约/消息/我的四个一级入口。
- (question) [OPEN QUESTION] 产品是否需要纳入陪诊员匹配、就医进度、服务订单与支付等已有 PRD 能力；本轮先把可替换的模块位留在 IA 中。
- (decision) 工作方式采用 fast path：对未确认的受众、业务范围、通知规则与数据状态使用显式假设，先形成可评审双契约。
- (decision) 主题命名为 清透青绿医疗（Clear Teal Care）：背景使用浅灰蓝降低临床冷感，主色青绿承载可信、可行动状态，深青墨用于正文与关键数字。
- (decision) 视觉层级采用大留白 + 白色卡片 + 柔和环境阴影；主色只用于可行动 CTA、当前预约、成功状态与选中导航，不用于整屏装饰。
- (decision) 中文排版优先系统无衬线字体，使用 20/24px 级标题、15/16px 正文、12/13px 辅助信息；避免参考图中的英文医疗营销话术。
- (decision) 首页 IA：问候与定位 → 主行动（找医生/预约）→ 当前预约 → 服务入口 → 推荐医生；关键任务在首屏可见。
- (decision) 底部一级导航固定为 首页、预约、消息、我的；消息和我的不以抽屉替代，适配微信小程序单手操作。
- (decision) 预约流程收敛为 医生列表 → 医生详情 → 日期/时间选择 → 患者信息确认 → 预约结果；每一步保留返回与状态恢复。
- (decision) 预约详情提供改期、取消、联系医生/陪诊支持与就诊提醒；涉及医疗风险的判断不由 UI 代替医生诊断。
- (decision) 状态模式覆盖首屏加载、空预约、无可用号源、网络失败、预约提交中、预约成功、取消确认与敏感健康信息保护。
- (assumption) [ASSUMPTION] v1 默认登录态为手机号/微信授权后进入，个人资料与就诊人切换放入“我的”；未设计注册营销页。
- (assumption) [ASSUMPTION] 首页示例数据使用医生、科室、预约时间等演示内容；真实科室、支付、服务价格与订单规则需接入 PRD 后复核。
- (decision) 图片使用边界：参考图归档并在设计说明中建立视觉映射；不直接使用整张拼图作为真实医生头像，不复制其英文文案或设备样机。
- (event) 输入 reconciliation 完成：参考图已纳入取色、卡片、预约层级与组件方向；英文文案、设备样机、具体医生/医院/价格未作为产品事实吸收。
- (event) Mock coverage confirmed：首页、预约选择、预约详情已提供视觉参考；医生列表、医生详情、就诊人确认、结果、消息与我的以双契约和关键流程为准，保持 spine-only。
- (event) 结构与文案标准检查完成：DESIGN.md 章节顺序符合 Google Labs 规范；EXPERIENCE.md 覆盖 Foundation、IA、Voice、Components、States、Interactions、Accessibility、Platform、Flows 与 Open Questions。
- (event) Reviewer Gate 未启动：本轮按 fast path 默认跳过额外 reviewer，保留开放问题供下一轮 Update/Validate。
- (event) spines finalized
- (change) 用户反馈：上一版主题偏深、与参考图差异大；要求更浅的主题色、更接近参考图的圆角 Tab、更大字体与更大气的模块，以服务中老年使用者。
- (override) 覆盖上一版视觉决策：不再以深青绿作为大面积预约卡背景；主视觉改为浅青绿、白色卡片、低对比灰蓝画布。
- (decision) 新视觉方向命名为 浅雾青绿医疗（Soft Aqua Care）：surface-base 使用近白浅青，primary 使用明亮柔和青绿，文字使用深灰青而非深青黑。
- (decision) 底部导航改为参考图式的白色悬浮圆角胶囊，四周留出页面底色；中心预约入口使用独立圆形主色按钮，选中态同时用颜色、形状和文字表达。
- (decision) 为中老年用户放大字号与触控区：display 32px、title 24px、body 18px、label 15px、caption 14px；主要点击区域不小于 48px。
- (decision) 首页服务模块由四列小入口改为 2×2 大模块，每个模块拥有更大的图标、标题和说明；优先减少首屏拥挤。
- (decision) 关键屏幕的设备外框改为参考图的白色圆角机身与黑色顶部听筒/刘海，降低深色边框造成的视觉偏差。
- (event) Update 版本渲染检查完成：浅雾青绿主题、白色圆角设备、悬浮圆角 Tab、中心圆形预约入口、2×2 大模块和放大字号已在首页/预约/详情参考稿中统一。
- (event) 更新后的视觉契约与体验契约一致：五项一级导航为首页、找医生、预约、消息、我的；主要触控目标 48–52px；中老年可读性要求写入 Foundation 与 Accessibility Floor。
- (event) spines finalized
