# 《陪诊流程SOP》输入对账

## 对账范围与输入

- **输入名称：** 本轮用户提供的《陪诊流程SOP》原始内容，覆盖诊前对接、方案理解、现场碰面、情绪破冰、诊中引导与记录、隐私/冲突/等待、服务结束取药/药品核对/报销凭证。
- **输入原始记录依据：** 项目变更记录中的“本轮新增 SOP 输入”（`_bmad-output/planning-artifacts/prds/prd-medpal-2026-08-11/.memlog.md:52-62`）及发现记录（`findings.md:56-59`）。
- **被核对文档：** `prd.md` 与 `addendum.md`。本次只写本对账文件，不修改 PRD 或 addendum。
- **判定口径：**
  - **完整保留：** 原始输入的动作、定性语气、时间要求和异常处理均在 PRD 中以可执行要求出现。
  - **部分保留/弱化：** 只保留了概念、展示或记录，没有保留原始动作的强度、时点或执行对象。
  - **改变：** PRD 对原始动作增加了限制、替换了动作含义，或将原始内容改成了不同的业务规则。
  - **未闭合：** PRD 已提到，但关键字段、责任、顺序或异常结果仍由 TODO 承载，不能视为已完成对账。

## 主要缺口汇总

1. **诊前时点与碰面定位细节被弱化：** 原始“诊前 1–2 天主动对接”被改成家属查看安排；入口、电梯前等具体碰面定位以及“时间确认”未成为明确必填动作。
2. **情绪破冰没有形成可执行任务：** PRD只有“迎接与破冰”标签和泛化话术提示，缺少情绪确认、开场安抚、完成条件与记录字段。
3. **方案理解从“最佳动线”降为“预计/建议动线”：** 标准/MDT 的字段已保留，但最佳动线的判断、变更和责任没有规则，且方案目录、资格、参与人和交付结果仍是 TODO-048。
4. **医学术语解释和用药原理存在语义改变：** PRD将医学术语解释限制为非诊断性流程术语，将“用药原理”限制为按处方/说明书核对；这比原始输入更窄，属于需要确认的安全性改写，不应默认为原始 SOP 已原样对账完成。
5. **异常与代取闭环仍不完整：** 首次联系失败、迎接异常、隐私/冲突/等待升级、患者等待安全、药品/凭证不一致，以及跨楼层取药后的“代取代送”尚未形成明确责任、阈值、顺序和结果状态。

## 对账结论

PRD 和 addendum 已覆盖 SOP 的整体阶段框架，以及提前 15–20 分钟到达、现场迎接、诊中任务卡、隐私提示、冲突/等待安抚、药品核对和报销凭证等大部分正常路径。未能完全对账通过的部分集中在：原始时间窗口和现场定位细节、情绪破冰的具体动作、最佳动线的确定性、医学/用药表达被收窄，以及多类异常分支和代取代送责任未闭合。
