# 陪诊师佣金增量审查（2026-08-18）

## Verdict

PASS — 0 Critical，0 Major。

## 审查范围

- 后台配置与订单佣金比例快照
- 服务结束/订单完成触发条件
- 佣金计算、待扣款抵扣和余额入账
- 重复结束、回调和人工重试的幂等性
- 售后/退款与佣金结算并发
- 陪诊师查看与提现闭环
- 与“不自动降佣”、取消扣款和邀请奖励余额的现有规则一致性

## 结论

- 新增 FR-039、FR-040 的边界明确，未改变订单主状态和 SOP 阶段定义。
- 比例配置不会追溯已支付订单，也不会触发系统自动降佣。
- 佣金结算拥有唯一动作、唯一流水和完整金额分解，重复请求不会重复入账。
- 待扣款抵扣与既有 FR-015 一致；余额不得为负。
- 售后/退款并发和入账后的处理方式已明确为暂停或人工处理，不会静默回滚余额。
- FR 稳定 ID 共 40 条，无重复定义。

## 后续可选细化

- 金额舍入规则、配置页面交互和具体权限可在架构/UX 阶段定义，不阻塞本期核心功能。
